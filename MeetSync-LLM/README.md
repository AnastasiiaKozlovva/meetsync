# MeetSync-LLM

Модуль интеграции с языковыми моделями (LLM) для проекта MeetSync.

## Назначение
Преобразование пользовательских сообщений о расписании и встречах на естественном языке в структурированные данные с последующей валидацией.

## Структура проекта
- `src/meetsync_llm/` — исходный код модуля
- `tests/` — модульные (unit) и интеграционные (integration) тесты
- `specs/` — техническое задание и документация требований
- `scripts/` — вспомогательные скрипты
- `.agents/` — правила и инструкции для ИИ-ассистентов
